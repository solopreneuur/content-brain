# Harvester ants run the internet's protocol

**The find:** Stanford biologist Deborah Gordon and computer scientist Balaji Prabhakar found that harvester ants decide how many foragers to send out the same way the internet's TCP protocol manages traffic. Foragers leave at the rate returning ants come back with food. If nobody returns for about 20 minutes, foraging stops.
**The surprise:** With no boss and no map, ants arrived at the method engineers invented in the 1970s, slow start included.
**The idea:** [Decentralised control](../../../concepts/decentralised-control.md). A simple feedback rule (send more when results come back, fewer when they don't) can run a whole system without anyone in charge.
